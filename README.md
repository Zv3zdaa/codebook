# Substring Codebook Builder

Прототип инструмента, который анализирует текст и строит **кодовый словарь
частых подстрок** — первый шаг к компрессору на основе подстрок.

## Что реально делает

1. Разбивает текст на слова.
2. Для каждого слова находит **все** подстроки и считает их частоты.
3. Оставляет `top-N` самых частых.
4. Присваивает каждой подстроке порядковый код (0, 1, 2, …).
5. Удаляет подстроки, чей код «длиннее», чем конкатенация кодов её символов
   (эвристика: хранить такую подстроку в словаре невыгодно).

**Результат** — словарь вида `{"substring": [frequency, code], ...}`.

## Что пока НЕ реализовано

- Замена подстрок кодами в тексте (собственно сжатие).
- Декодирование обратно.
- Бинарный формат вывода и подсчёт реального коэффициента сжатия.

Эти шаги — в Roadmap.
